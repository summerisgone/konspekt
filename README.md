# Konspekt

Konspekt записывает звонки в Яндекс Телемост и делает конспект встречи.

Во время звонка приложение записывает ваш микрофон и звук звонка, после окончания
расшифровывает запись через OpenAI-совместимый ASR-сервис и формирует краткое резюме.

Работает на macOS и Windows. Ниже описана macOS, отличия для Windows - в разделе [Windows](#windows).

## Требования

- macOS 14.2 или новее
- Command Line Tools (`xcode-select --install`), Xcode не нужен

## Установка

```bash
scripts/install.sh
```

Скрипт собирает `Konspekt.app`, копирует его в `~/Applications`, создает LaunchAgent
`ru.konspekt.agent` и запускает фоновый процесс.

Конфигурация копируется из `./.env` в `~/.config/konspekt/.env` (только если этого файла
еще нет, права `600`). Файл `./.env` должен существовать при первой установке.

### Из релиза

Скачайте `Konspekt.zip` из GitHub Releases, распакуйте и переместите `Konspekt.app`
в `~/Applications` или `/Applications`. Откройте приложение, заполните настройки
инференса, нажмите "Сохранить", затем "Запустить": приложение само создаст LaunchAgent.

## Разрешения

При первом запуске macOS попросит разрешения:

- Микрофон
- Запись системного звука (System Audio Recording)
- Доступ к папке Документы (для записи в `~/Documents/Konspekt`)

## Где лежат файлы

Каждый звонок сохраняется в `~/Documents/Konspekt/<date_time>/`, где `<date_time>` - дата и время
начала записи, например `2026-10-21_10-05-03`:

- `mic.caf` - запись микрофона
- `call.caf` - запись звука звонка
- `transcript.md` - расшифровка с именами участников
- `speakers.json` - кто и когда говорил (участники, реплики, отпечатки голосов)
- `summary.md` - резюме
- `status.json` - статус обработки

## Участники и база голосов

На macOS 15 и новее запись размечается по говорящим локально: микрофон и звук звонка
делятся на реплики отдельно (pyannote + WeSpeaker на Core ML, через
[FluidAudio](https://github.com/FluidInference/FluidAudio)), затем каждая реплика распознается
отдельным запросом к ASR. Звук никуда, кроме ASR-сервиса, не отправляется. При первой обработке
скачиваются модели (~21 МБ) с Hugging Face в `~/Library/Application Support/FluidAudio/Models`.

Неизвестные голоса называются "Спикер 1", "Спикер 2"... Кнопка "Участники" у звонка в окне
настроек показывает долю речи и шкалу реплик каждого участника, дает послушать голос и задать имя.
После сохранения расшифровка переписывается, конспект пересобирается, а голос запоминается в
`~/.config/konspekt/voices.json`: в следующих звонках этот человек будет подписан автоматически.

Если разметка не удалась (или на macOS 14 и Windows), расшифровка делается как раньше, без имен.

## Командная строка

```bash
~/Applications/Konspekt.app/Contents/MacOS/konspekt status
~/Applications/Konspekt.app/Contents/MacOS/konspekt retry
~/Applications/Konspekt.app/Contents/MacOS/konspekt process <dir>
```

- `status` - состояние записей и обработки
- `retry` - повторить обработку записей с ошибкой
- `process <dir>` - обработать конкретную папку записи

## Логи

```bash
tail -f ~/Library/Logs/konspekt.log
```

## Настройка

Файл `~/.config/konspekt/.env`:

- `OPENAI_BASE_URL` - адрес OpenAI-совместимого API
- `OPENAI_API_KEY` - ключ API
- `OPENAI_MODEL_NAME` - модель ASR (распознавание речи)
- `SUMMARY_MODEL_NAME` - модель для резюме (необязательно, по умолчанию `qwen-3.8-27b`)
- `KONSPEKT_DIR` - папка для записей (необязательно, по умолчанию `~/Documents/Konspekt`)
- `TRANSCRIPTION_PROMPT_FILE` - файл с промптом для ASR (необязательно): передается в поле `prompt`
  запроса `audio/transcriptions`, подходит для имен, терминов и стиля расшифровки
- `SUMMARY_PROMPT_FILE` - файл с системным промптом для резюме (необязательно): заменяет встроенный

Промпты можно выбрать и отредактировать в окне настроек (кнопка "Изменить..."). Если файл не задан,
редактор создаст его в `~/.config/konspekt/`; для промпта саммари в нем будет встроенный промпт.

Файлы промптов читаются при каждом запросе, перезапуск после правки не нужен. Пустой файл означает
поведение по умолчанию. Если файл недоступен, обработка завершится ошибкой и ее можно повторить через `retry`.

## Удаление

```bash
scripts/install.sh --uninstall
```

Скрипт останавливает агент, удаляет LaunchAgent и `~/Applications/Konspekt.app`.
Конфигурация `~/.config/konspekt` и записи в `~/Documents/Konspekt` сохраняются.

## Windows

Требования: Windows 10 2004 или новее (нужен захват звука отдельного процесса), десктопное
приложение Яндекс Телемост. Звонки в браузере не записываются, как и на macOS.

Звук звонка пишется только из процесса `YandexTelemost.exe` и его дочерних процессов, микрофон -
с устройства ввода по умолчанию. Разрешения не запрашиваются.

### Установка из релиза

Скачайте `Konspekt-windows.zip` из GitHub Releases, распакуйте в любую папку и запустите
`KonspektTray.exe`. В трее появится значок; при первом запуске откроется файл настроек в Блокноте.
Заполните его и сохраните: демон запустится сам. Автозапуск включается в меню значка
("Запускать при входе в Windows").

### Сборка и установка из исходников

Нужны [Swift для Windows](https://www.swift.org/install/windows/) 6.1 или новее и Visual Studio
Build Tools с компонентами MSVC и Windows SDK.

```powershell
scripts\install-windows.ps1
```

Скрипт собирает приложение (`scripts\build-windows.ps1`), копирует его в
`%LOCALAPPDATA%\Programs\Konspekt`, копирует `.\.env` в `%APPDATA%\Konspekt\.env` (если там еще
нет файла), включает автозапуск и запускает значок в трее.

Удаление: `scripts\install-windows.ps1 -Uninstall`. Конфигурация и записи сохраняются.

### Отличия от macOS

- Вместо окна настроек - значок в трее: запуск и остановка демона, автозапуск, последние звонки,
  папка записей, лог. Пункт "Настройки..." открывает `.env` в Блокноте; после сохранения файла
  демон перезапускается сам (если не идет запись).
- Конфигурация: `%APPDATA%\Konspekt\.env`, ключи те же.
- Записи: `mic.wav` и `call.wav` вместо `.caf`, папка по умолчанию - `Документы\Konspekt`.
- Лог: `%LOCALAPPDATA%\Konspekt\konspekt.log`.
- Командная строка: `konspekt.exe status | retry | process <dir>` из папки установки.
